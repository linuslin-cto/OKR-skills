# Examples — paste-ready templates

Prefer these shapes when drafting or reviewing; swap nouns/numbers for the user’s industry.

---

## 1. Company OKR (standard)

```markdown
## Mission (stable)
We help ______ in ______ by ______.

## This quarter’s OKR (usually one O)
**O:** ______ (inspiring, time-bound, owned by this org)

| KR | Metric & target | Confidence |
|----|-----------------|------------|
| KR1 | ______ | 5/10 |
| KR2 | ______ | 5/10 |
| KR3 | ______ | 5/10 |

## Explicitly not doing (protect focus)
- ______
- ______

## Next Monday P1s (≤3)
1. ______
2. ______
3. ______
```

### Industry sketch (e-commerce growth — structure only)

```markdown
**O:** Make the core category the repurchase default — not a discount race

| KR | Target | Confidence |
|----|--------|------------|
| KR1 | Core category monthly repurchase 22% → 35% | 5/10 |
| KR2 | NPS ≥ 8 | 5/10 |
| KR3 | Self-serve orders ≥ 70% (cut manual entry) | 5/10 |

Not doing: three edge categories; full brand VI redo.
```

### Anti-pattern → rewrite

| Anti-pattern | Problem | Rewrite |
|--------------|---------|---------|
| O: Revenue +30% | That’s a KR | Make O directional; move 30% to KR |
| O: Improve UX | Not checkable | Add KRs: NPS / critical-task time |
| 5 company Os | No focus | Merge to 1; rest → dept or not-doing |
| All KRs = revenue | Short-term gambling | Mix quality / retention / capability |

## 2. Department OKR (aligned to a company KR)

```markdown
**Company anchor:** Supports company KR_: “______”

**Dept O:** ______

| KR | Verifiable outcome (not a task list) | Confidence |
|----|--------------------------------------|------------|
| KR1 | ______ | 5/10 |
| KR2 | ______ | 5/10 |
```

### Coaching question chain (eng ↔ sales hard to measure)

1. At quarter end, how do we know we “helped” sales/biz?  
2. Shared definition of “major prospect”?  
3. What’s the historical baseline?  
4. If we did the activity but lost the deal, is that success? → **outcome metric**  
5. Can we frame positively (e.g. tech qualification rate) instead of “≤ N failures”?

## 3. Monday four-quadrant agenda (15–30 min)

```markdown
# Monday OKR sync — YYYY-MM-DD

## 1. This week’s focus (3–4, ordered)
1. [ ] ______
2. [ ] ______
3. [ ] ______

## 2. Next four weeks — needs from others
- Who / when / what: ______

## 3. OKR confidence (vs last week)
| KR | Last week | This week | Why (1 line) |
|----|-----------|-----------|--------------|
| KR1 | _/10 | _/10 | |
| KR2 | _/10 | _/10 | |
| KR3 | _/10 | _/10 | |

## 4. Health metrics (pick 2)
- Customer / team / system: ______ → threat to OKRs?

## Must ask
- Will this priority list move the OKRs?
- Who can help? Are dependencies informed?
- Exhaustion or hidden risk?

Rule: conversation & coordination — ban laundry-list theater. ~1/4 look back, rest look forward.
```

## 4. Friday win session (outline)

```markdown
# Friday wins — YYYY-MM-DD (30–45 min)
Each person/group 3–5 min — show **visible outcomes this week**:
- Eng: demoable increment
- Product/design: prototype or decision
- Sales: signed / stage progress
- CS: notable customer save
- Other: OKR-relevant small win

Close: one line “what I want to show next Friday” → drives next week’s P1.
```

## 6. MVP / kanban card

```markdown
**Hypothesis (not “it will definitely work”):** If we build ______, users will ______.

**KRs (how we falsify/confirm):**
- KR1: ______ (measure-by date: ____)
- KR2: ______

**Why before other work:** Aligns to company KR_ “______”
**Due review:** What did we learn? Keep / iterate / kill?
```
