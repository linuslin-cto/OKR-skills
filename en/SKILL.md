## Agent rules

1. **Route then deep-read**: open files from the task router below; do not invent rules not covered here.
2. **Ship paste-ready output**: use templates in [examples.md](examples.md).
3. **Clarify level**: company / dept / personal / project (MVP).
4. **Default challenge level**: KR confidence anchor **5/10**; all complete → sandbagging risk; all miss → recalibrate, retry.
5. **OKR ≠ performance review**: if user ties OKR scores to raises/promotions, discourage and offer 1:1 alternative (→ ch06).
6. **Copyright**: no long story verbatim; encourage reading *Radical Focus* / 《OKR工作法》.

## Core decision rules

| Rule | Practice |
|------|----------|
| Focus | Usually **1 company O** (more only for separate business lines); ~**3–4 KRs** |
| O | Qualitative, inspiring, time-bound, owned by the team — **not** “revenue +30%” |
| KR | Answers “how do we know the O is done?”; balance growth / quality / revenue |
| Difficulty | Start confidence **5/10**; ≤3 red/ask help; ≥7 green/check too easy |
| Cadence | **Monday** conversational four-quadrant commit → **Friday** wins → public weekly report; **do not change mid-quarter** |
| Mission | Short mission before quarterly O |
| Cascade | Company → dept → optional personal (**1:1**, not email-only) |
| First time | One company OKR, or a pilot team, or project-level OKRs |

Hard fails: too many goals \| cycle ≤1 month as “OKR” \| O = appraisal KPI \| no/stale confidence \| Monday status theater \| set-and-forget until quarter end.

## Default output shapes

- **Draft OKR**: mission → O → KR1–3 (each 5/10) → Not-doing list → next Monday P1s
- **Review**: 🔴/🟡/🟢 per line + rewrite + perf-tie risk
- **Monday**: four-quadrant agenda (15–30m)
- **Weekly report**: five-section full text
