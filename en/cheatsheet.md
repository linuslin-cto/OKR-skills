# Cheatsheet

> Paste-ready templates: [examples.md](examples.md). This page is decisions + health checks only.

## Decision rules
| When | Do | Because |
|------|-----|---------|
| Company goal | Usually **1 O** | Unmemorable = unfocused |
| Write O | Inspiring + time-bound + independently doable | KPI sentences are KRs |
| Write KRs | 3–4 measurable; balance growth/quality/revenue | All-revenue → short-term gambling |
| Set difficulty | Confidence **5/10** | Too easy = sandbag; too hard = despair |
| Execution drift | Monday four-quadrant + Friday wins | Setting ≠ finishing |
| Dept says “we can’t measure help” | Coach to positive outcome metrics | Activity ≠ contribution |
| Want mid-quarter OKR change | Don’t; finish and learn | Stable focus |
| First rollout | One OKR / pilot team / project-level | Reduce disillusionment |
| Raises/promotions | 1:1s — never OKR scores | Coupling causes sandbagging |
| Weekly report | OKR+confidence → last week → next 3 → risks → notes | Coordination, not theater |
| Agent output | Paste-ready templates in the user’s language | Framework talk alone isn’t useful |

## Monday four quadrants
1. This week’s 3–4 critical tasks (ordered)  
2. Next four weeks — what others must prepare  
3. OKR confidence: up/down vs last week? why?  
4. Health metrics: customer / team / system  

Ask: Will this list move the OKRs? Who can help? Are dependencies aware? Is the team exhausted?

## Confidence colors
- ≤3 red → unblock / add help now  
- 4–6 normal challenge band (5 = anchor)  
- ≥7 green → check if too easy  

## O vs KR
| Better as O | Actually a KR (don’t use as O) |
|-------------|--------------------------------|
| Ship a great MVP | Revenue +30% |
| Win South Bay café retail | Double users |
| Close a funding round | Series B revenue to $5M |

## Pitfall checklist (hard fail)
- [ ] Multiple company objectives  
- [ ] Cycle ≤ 1 month called an OKR  
- [ ] Objective = appraisal metric  
- [ ] No confidence index / never updated  
- [ ] Monday = status theater  
- [ ] Set and ignore until quarter end  

## Seven-step quarterly rollout (short)
Collect ideas → leadership sets OKRs → dept sessions → CEO check → cascade → optional personal 1:1 → all-hands kickoff (finish setup within ~2 weeks)
