# Chapter 6: 最后的建议

> **何时读**：OKR 与绩效/加薪脱钩、恢复「目标魔力」、作者操作清单。用户一提挂钩考核 → 必读。

## Core Idea
恢复目标的「魔力」：让目标重新鼓舞日常行为，而不是服务年度评估表格。OKR 用来挑战上限；绩效、升职、加薪走持续一对一——**切勿挂钩**。

## Frameworks Introduced
- **绩效考核驱动目标 vs 目标驱动绩效**（黛德丽·帕克纳德）  
  当目标为年终评估而写，员工优先自保；合同锁定后目标失真。年轻公司若仅 CEO 钦定目标、不进入日常时间分配，同样无效。
- **恢复魔力的 5 步**
  1. 用目标定义并驱动成功（务实、有优先级；管理者常高估「大家都懂」——书中称仅约 7% 真正理解）。
  2. 拒绝学院派「最可能达成」的低目标；OKR 找**可能完成的最大目标**；勿与绩效评估挂钩。
  3. 实时追踪（周度执行与分解指标）；月/季才看会发现跑偏与停滞。
  4. 邮件/看板让人 **3 秒内**看到自己的目标与进度；高绩效者每天先审视目标再分配时间。
  5. 自上而下设置兼自下而上；硬控扼杀创新与机会。
- **如何评估绩效**：每月至少两次一对一，覆盖投入度、绩效、协同（如 1–5 分互评）；一年约 24 次校准，年终无意外。
- **作者最后建议清单**（操作摘要）
  - 公司级通常只设一个 OKR（多业务线例外）
  - 给自己约三个月挑战期；一周能完成的不算挑战
  - 目标不要写成传统绩效考核指标；要能鼓舞
  - 周盘点：先公司再部门；个人一对一；每周确认进度
  - 自上而下关联；OKR 是「必须做成的那一件」，不是任务筐
  - 周一是谈话：信心、状态、优先级变化
  - 鼓励自下而上建议；OKR 公开（如内网）
  - 周五庆祝缓冲周一严酷

## Key Concepts
- **目标魔力 / 自由意志感**
- **Workboard 类工具**：日常聚焦与跨部门透明（文中语境）
- **格鲁夫 / 杜尔 / 谷歌 / Zynga 谱系**：框架来源与传播（致谢）
- **可改编**：谷歌做法与创业公司节奏不同；按组织改，勿原样照搬

## Mental Models
- Prefer **目标驱动日常** over **评估驱动目标文书**。
- Use **高频一对一** when 想取消「年终惊喜考核」。
- Treat **公开透明** as 聚焦的基础设施。

## Anti-patterns
- OKR 分数直接决定加薪晋级。
- 只宣布一次目标再不提。
- 个人 OKR 在大周会上逐个审讯。
- 把每个任务塞进 OKR。
- 无周五缓冲的纯压榨节奏。

## Worked Example
绩效对话改版：月内两次一对一各打投入度/绩效/协同分并交换看法 → 问题当周修 → 年终只是又一次已知事实的汇总交流。  
与此同时 OKR 周周公开、信心更新——两套系统并行、职责分离。

## Key Takeaways
1. OKR 与绩效考核解耦是发挥挑战性的前提。
2. 目标要进每天的时间分配与三秒可见处。
3. 周节奏 + 公开 + 上下结合。
4. 一个公司 OKR、一季时长、谈话式周一、庆祝式周五。
5. 按公司规模改编，保持聚焦原则不变。
