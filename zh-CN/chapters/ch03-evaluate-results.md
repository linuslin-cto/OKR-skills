# Chapter 3: 评估 OKR 实施成果

> **何时读**：设计周五胜利会、季末盘点、判断「全完成=藏实力」。周一四象限细节 → ch04。

## Core Idea
评估不只在季末：用 **周五胜利会议** 制造周度小胜与跨部门可见性；用季末盘点校准难度——**全完成往往意味着目标太容易（隐藏实力）**。

## Frameworks Introduced
- **周五胜利会议（Victory Meeting）**：每周展示本周成果（工程演示、设计、销售订单、客服案例等）。
  - When to use: 目标远大、日常挫败感高、部门彼此不了解时。
  - How: 固定周五；全员可展示；配合简单犒劳；让「想有东西可分享」驱动周内努力。
- **承担责任—庆祝成果 的周循环雏形**：周一计划与担责，周五庆祝；中间复杂沟通照常。
  - When to use: 已设 OKR 但办公室气氛沉闷、周末无感时。
  - How: 固化周一/周五仪式，避免「静悄悄结束的一周」。
- **季末盘点校准难度**：
  - 全 KR 完成 → 可能藏实力，下季加难。
  - 部分高难度 KR 完成 → 健康挑战。
  - 全失败 → 认清能力与计划，下季调整（详见 Ch4/Ch5）。

## Key Concepts
- **演示 / Demo**：工程与产品用可见产物对齐「是否朝真目标前进」。
- **隐藏实力（sandbagging）**：为好听话把目标设低。
- **P1 过滤**：不服务于当前最高优先级的工作，即使「做得好看」也可停。
- **半年/一年盘点**：看复购线上化、新产品线、融资等里程碑是否由聚焦堆叠而来。

## Mental Models
- Use **周度小胜** when 季度目标太远导致无力感。
- Prefer **加难** when 团队「自我感觉良好但无成长」。
- Think of 庆祝 as **执行系统的一部分**，不是福利点缀。

## Anti-patterns
- **只在季末才看 OKR**。
- **完成全部 KR 就开香槟却不反思难度**。
- **周五变成加班炫耀或走过场**。
- **用庆祝掩盖战略偏离**。

## Worked Example
TeaBee：拉斐尔推动周五演示与啤酒派对；销售首次中西部大单在会上公开；杰克因非 P1 结束设计师合作。  
一季后全 KR 完成 → 拉斐尔泼冷水「隐藏实力？」→ 团队重设更难目标，同时保留周五胜利会——**庆祝与加难可以并存**。

## Key Takeaways
1. 周度可见进展 > 季末惊吓。
2. 周五胜利会提升士气与跨部门理解。
3. 全完成 ≠ 完美，可能是目标太易。
4. 聚焦包含对非 P1 工作说不。
5. 多年增长是每周担责+庆祝的复利。
