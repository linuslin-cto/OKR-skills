# Chapter 4: 影响目标达成的关键因素

> **何时读**：诊断「为什么达不成」、正式 O/KR 原则、信心指数、周一四象限。议程模板 → [examples.md](../examples.md)。

## Core Idea
目标达不成，很少是「不够想要」，而是缺优先级、缺重复沟通、缺计划系统、没把时间花在重要事上、或失败一次就放弃。OKR 要配上 **使命、正确的 O/KR 写法、信心指数，以及周一担责 / 周五庆祝**。

## Frameworks Introduced
- **无法达成目标的 5 个关键因素**
  1. 没有优先级（事事重要 = 事事不重要）→ 单一目标 + 约 3 个 KR。
  2. 沟通不足 → 「当你说得不想再说，人们才开始听」；渗入周会、邮件、项目。
  3. 没有计划/系统 → 意志力不可靠；用承担—庆祝—盘点托住疲劳期。
  4. 时间没花在重要事上 → 重要不紧急被紧急事挤掉；周一为 OKR 留时间与期限感。
  5. 轻易放弃 → 首次失败各有原因（过易/过难/设完就忘）；成功者共同特点是追踪有效无效并重试。
- **先使命再 OKR**：短、易记、指导性；与 O 相似但时间跨度更长（年 vs 季）。
- **设定目标 3 原则**：① 明确方向且鼓舞人心；② 有时间期限（月/季，不是一年战略）；③ 由独立团队可执行（少甩锅依赖）。
- **KR 要量化且难但非不可能**：用「如何确认达成」倒推；常用增长/激活/收入/性能/质量；信心指数默认 **5/10**。
- **自上而下关联**：公司 → 部门（可咬住单个 KR 或整体）→ 个人（可选，含成长项）。
- **产品团队注意（马蒂·卡根）**：OKR 应落在跨职能产品团队对业务的贡献，避免与职能个人目标打架。
- **周一四象限 + 周五胜利者**
  - 本周关注任务（3–4 件）｜未来四周计划｜OKR 信心状态｜状态指标（客户/团队/系统等）
  - 会议基调：相互支持，而非刷存在感；建议 1/4 时间讲进展、其余谈下一步。

## Key Concepts
- **信心指数（1–10）**：对达成 KR 的主观概率锚。
- **状态指标**：非 KR 本身，但会拖垮 OKR 的健康信号。
- **NPS 等质量代理指标**：让「质量」可衡量。
- **惩罚失败文化**：会系统性地制造过低目标。

## Mental Models
- Use **单一公司 O** when 想让全员背得出目标。
- Prefer **系统与节奏** over 「靠意志扛过一季」。
- Treat **50% 失败预期** as 健康定位，不是甩锅许可证。
- **季中不改 OKR**：烂也跑完，下季学。

## Anti-patterns
- 同时推很多公司目标。
- 设完 OKR 直到最后一周才看。
- 目标写成纯财务 KPI 句。
- 周一会变成汇报批斗会。
- 把所有日常任务塞进 OKR。

## Worked Example
四象限周一会示例问题：  
「这个优先级列表能确保 OKR 完成吗？谁能帮我们？市场是否知道产品下周动作？团队是否筋疲力尽、产品是否有隐患？」  
只讨论这四块，信任日常选择，把时间留给协同与阻碍。

## Key Takeaways
1. 先诊断五因素，再怪「OKR 没用」。
2. 使命定向，OKR 给里程碑。
3. O 鼓舞 + 有期限 + 可独立执行；KR 可量化且具挑战。
4. 5/10 信心 + 每周更新。
5. 周一担责、周五庆祝，周周重复。
