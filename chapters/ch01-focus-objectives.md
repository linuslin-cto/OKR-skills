# Chapter 1: 确定目标，确保团队聚焦到重要目标上

> **何时读**：起草首个 O/KR、纠结使命 vs 策略、校准挑战难度。模板 → [examples.md](../examples.md)。

## Core Idea
创业与增长的第一课不是「多做事」，而是在使命不变时敢于调整策略，并用 **一个有挑战的目标 + 少量可衡量关键结果** 把团队钉在真正重要的事上。

## Frameworks Introduced
- **使命 vs 策略**：使命（如「让喜欢喝茶的人喝到好茶」）可稳定；销售渠道、包装、人员配置属于策略，可随现实调整。当渠道/客户选择与使命冲突时，先辨认冲突再决策。
  - When to use: 大单、新渠道、人事变动动摇「我们到底在做什么」时。
  - How: 写下使命 → 对照当前最大动作是否服务使命 → 保留使命、改策略或拒绝交易。
- **O + KR 入门结构**（投资人吉姆引入）：每季一个有挑战、方向明确的目标；配套 3–4 个具体结果指标证明目标完成。
  - When to use: 团队忙但进展感弱、资源分散时。
  - How: 问「未来三个月最棘手且值得齐心解决的是什么？」再问「怎样才算证明我们做到了？」
- **挑战难度校准**：关键结果要难但非不可能；过低（藏实力）与过高（全员沮丧）都有害。
  - When to use: 首次写 KR 数值时。
  - How: 用「一半把握能达成」作为心智锚点（后文章化为 5/10 信心指数）。

## Key Concepts
- **Objective（目标）**：方向与鼓舞，非单纯数字句。
- **Key Results（关键结果）**：量化「目标是否达成」。
- **留存/复购类指标**：比单纯砍价更能衡量「提供了价值」。
- **在线交易系统等能力建设**：可纳入 KR，使运营可规模化。
- **乐观与执着**：创业存活率极低，需心态支撑，但不能替代聚焦。

## Mental Models
- Prefer **改策略、保使命** when 短期收入诱惑与长期定位冲突。
- Use **「价值证明」类目标** when 只追订单金额会偏离客户质量。
- Think of OKR as **聚焦装置**，不是融资故事的装饰。

## Anti-patterns
- **单边市场硬推**：供给很多、需求很少仍堆功能/包装。
- **大单即战略**：餐厅供应商大合同若损害「好茶」定位，需诚实权衡。
- **目标过易或过难**：30% 过保守、100% 不现实——用挑战但可搏的区间。

## Worked Example
TeaBee 在投资人引导下设定季度方向：向餐厅供应商证明「一流茶叶带来增长」。  
讨论后的 KR 方向示例（故事中）：高挑战复购率、优化在线交易以降低人工输单。  
要点：先对齐「价值是什么」，再选可观察指标，而不是先写收入口号。

## Key Takeaways
1. 使命指导取舍；策略可以变。
2. 每季问：最重要且棘手的一件事是什么？
3. O 定方向，KR 证明到达；数值要有挑战。
4. 能力建设（如自助下单）可以成为 KR。
5. 聚焦比「什么都做一点」更能救命。
